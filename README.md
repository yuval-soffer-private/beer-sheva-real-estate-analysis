# Be’er Sheva Real Estate Market Analysis

Independent data analysis project conducted in collaboration with Noor Lab and the Be’er Sheva Innovation District.

## Objective
Explore real estate transaction patterns and compare trends within the Innovation District with the wider Be’er Sheva market and other cities.

## Approach
Data cleaning, integration of transaction tables, feature engineering, exploratory visualizations, correlation analysis, ANOVA and time-series comparisons. The notebook includes the original saved analytical outputs.

## Data availability and provenance
The analysis uses real estate information that was publicly viewable through external information systems. Source datasets are **not redistributed** in this repository. Public visibility does not necessarily grant bulk collection or redistribution rights. The original acquisition method is not documented or reproduced here; no claim is made that it was an official API or authorized bulk export. Some displayed examples and summary outputs remain in the notebook.

## Reproducibility
The notebook requires separately obtained, appropriately authorized input files. Local file paths in the notebook are illustrative and the pipeline has **not** been re-run after preparation for publication. Historical outputs are preserved; they are not evidence of a fresh execution.

## Scope
This repository is intended as a portfolio demonstration of the analytical work, not as a downloadable real estate dataset.
